- Standalone SwanStation PlayStation 1 emulator front-end written in Rust with egui
- TV/controller-first launcher, file browser and pause menu
- 39 embedded themes, JAPS1ME as the default, plus external theme support
- Memory Card Manager for `.srm`, `.mcd` and DexDrive `.gme` cards
- DuckStation/RetroArch card import and safe `.japs1me-bak` backups
- JPG screenshots via `F12` or the pause menu
- Multi-disc `.m3u` swapping from the pause menu without restarting the core
- Save states, memory cards, BIOS management and controller configuration
- No Discord integration, no RetroAchievements, no online service prerequisites
